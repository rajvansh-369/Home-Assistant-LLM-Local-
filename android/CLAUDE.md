# Aster (Android app)

Aster is a React Native (Expo, TypeScript, expo-router) app for Android: a household AI
assistant that talks to a Laravel API (`../backend`) and a home-network LLM, zypherLL (`../llm`).
Built: the first run (1.1–1.5, 2.2 first-run mode), home mode with chat (2.1 Who's using,
2.2 for any profile, 2.5 Guest, 3.1/3.2 Home, 3.3 Chats, 3.4/3.5 streaming chat, 5.1 Settings),
reminders and location (3.1/3.2 "Coming up", the reminder editor, reminder notifications,
location points and uploads, 5.3 Location), messages and spoken alerts (message capture from
notifications, VIP spoken alerts with the app closed, 4.1 Messages, 4.2 Thread with suggested
replies, 4.3 Spoken alerts, the VIP editor, 4.4 home notices, the 3.1/3.2 cards), and profiles,
memory and activity (2.3 Profiles, 2.4 Edit profile, 5.2 Memory and activity, 5.1 Privacy and
Your data).
It runs as a development build (`npx expo run:android`), never Expo Go. Dark theme only.

Plans and source of truth: `docs/aster-first-run-plan.md` (first run, phases in §8),
`docs/aster-home-chat-plan.md` (home mode and chat, phases H1–H7),
`docs/aster-reminders-location-plan.md` (reminders and location, phases R1–R6),
`docs/aster-messages-alerts-plan.md` (messages and spoken alerts, phases M1–M6),
`docs/aster-profiles-memory-plan.md` (profiles, memory and activity, phases P1–P6) and
`docs/aster-voice-plan.md` (voice and the wake word, phases V1–V6; planned).
Status: `docs/*-status.md`.

## Commands

```bash
npm run android     # expo run:android (dev build; needs a device/emulator)
npm start           # Metro only, for an already installed dev build
npm run typecheck   # tsc --noEmit
npm run lint        # expo lint
npm test            # jest (jest-expo preset)
npx expo install <pkg>   # add dependencies (SDK-matched versions)
```

Config: `app.config.ts` reads `.env` (copy `.env.example`). `android/` and `ios/` are
generated by prebuild and stay out of git.

## Rules

- Colours, fonts and sizes come only from `src/theme`.
- Screen text comes only from the features' `copy.ts` files (first-run, profiles, home, chat,
  settings, reminders, location, messages, memory). The native alert engine's words come from
  `features/messages/copy.ts` too (handed over with the rules).
- Captured messages never leave the phone except to the home PC's local model; never log them.
- Canvas sample data (Rohan, Sunrise Residency, …) is never a default value.
- Android only. Skip iOS work.
- Never log tokens, PINs or passwords.
- Custom fonts: set `fontFamily` per weight (see `src/theme/fonts.ts`), never `fontWeight`.
- The plans in `docs/` are the source of truth; report any deviation instead of making it
  silently.
