# Aster (Android app)

Aster is a React Native (Expo, TypeScript, expo-router) app for Android: a household AI
assistant that talks to a Laravel API (`../backend`) and a home-network LLM, zypherLL (`../llm`).
Current work is the first run: 1.1 Welcome, 1.2 Sign in, 1.3 Create Owner, 1.4 Set home,
1.5 Permissions, plus 2.2 Unlock in first-run mode, ending on a 3.1 Home placeholder. It runs
as a development build (`npx expo run:android`), never Expo Go. Dark theme only.

Plan and source of truth: `docs/aster-first-run-plan.md` (phases in §8).

## Commands

```bash
npm run android     # expo run:android (dev build; needs a device/emulator)
npm start           # Metro only, for an already installed dev build
npm run typecheck   # tsc --noEmit
npm run lint        # expo lint
npm test            # jest (jest-expo preset)
npx expo install <pkg>   # add dependencies (SDK-matched versions)
```

Config: `app.config.ts` reads `.env` (copy `.env.example`). `android/` and `ios/` are
generated by prebuild and stay out of git.

## Folders

```text
src/app/                     routes (expo-router); only screens and _layout files
  _layout.tsx                fonts, providers, launch routing
  (first-run)/               welcome, sign-in, create-owner, unlock-owner, set-home, permissions
  home.tsx                   3.1 placeholder
  dev/gallery.tsx            component gallery, dev builds only
src/theme/                   colors, typography, spacing, map style
src/components/              shared components (plan §3)
src/features/first-run/      copy.ts, validators.ts, routing.ts, store.ts
src/services/api/            client, types, auth, profiles, places, mock
src/services/llm/            health.ts
src/services/permissions/    one entry per Permissions row
src/services/secure.ts       expo-secure-store wrapper
src/tasks/                   geofence-task.ts
modules/aster-system/        local Expo module (Kotlin)
plugins/                     config plugins (with-home-llm-cleartext.js)
__tests__/                   jest tests (never inside src/app)
docs/                        plan, design images, screenshots, status
```

## Rules

- Colours, fonts and sizes come only from `src/theme`.
- Screen text comes only from `src/features/first-run/copy.ts`.
- Canvas sample data (Rohan, Sunrise Residency, …) is never a default value.
- Android only. Skip iOS work.
- Never log tokens, PINs or passwords.
- Custom fonts: set `fontFamily` per weight (see `src/theme/fonts.ts`), never `fontWeight`.
- `docs/aster-first-run-plan.md` is the source of truth; report any deviation instead of
  making it silently.
